# Security Policy

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 1.x     | ✅ Supported       |

## Reporting a Vulnerability

We take the security of InfraGuard Workbench seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to the maintainers.

You should receive a response within 48 hours. If for some reason you do not, please follow up to ensure we received your original message.

## What to Include

- Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit it

## Scope

This security policy applies to the InfraGuard Workbench codebase and its official Docker images. It does not apply to third-party dependencies — please report those to the respective maintainers.

## Preferred Languages

We prefer all communications to be in English.

## Policy

- We will acknowledge receipt of your vulnerability report within 48 hours
- We will send you a more detailed response within 72 hours indicating next steps
- We will keep you informed of the progress towards a fix
- We will notify you when the vulnerability is fixed
- We will publicly disclose the vulnerability after the fix has been released

## Disclosure Timeline

We aim to follow a 90-day disclosure timeline for vulnerabilities:
- **Day 0**: Report submitted
- **Day 2**: Acknowledgment sent
- **Day 7**: Initial assessment completed
- **Day 30**: Fix being developed or deployed
- **Day 60**: Fix released
- **Day 90**: Public disclosure (if not yet resolved)

## Bug Bounty

This project does not currently offer a bug bounty program. We still welcome and appreciate all responsible disclosures.
